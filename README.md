# ALTAI — A Journey Within

Учебный концепт лендинга зимнего путешествия на Алтай: пять дней, одна тёплая база, прогулки и время для себя.

**Сайт:** https://filinina2013-cloud.github.io/ALTAI/

- Адаптив: ПК (1440), планшет (768–1100), телефон (390)
- Служебные страницы: 404, 500, «Спасибо», политика, согласие, оферта, cookie
- Статичный HTML/CSS/JS без сборщика; плавный скролл — [Lenis](https://github.com/darkroomengineering/lenis)

> Учебный проект: даты, цены и контакты условные, форма заявки никуда не отправляет данные.

Часть видеоматериалов — автор [Ярослав Шураев](https://www.pexels.com/@yaroslav-shuraev/) (Pexels).
